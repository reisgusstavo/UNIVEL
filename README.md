☕ Exercícios de POO em Java

Repositório destinado ao armazenamento e organização dos exercícios, atividades e práticas desenvolvidas na disciplina de Programação Orientada a Objetos (POO) utilizando a linguagem Java durante a graduação.

📚 Sobre o projeto

Este projeto reúne os exercícios realizados ao longo da disciplina, com o objetivo de registrar minha evolução no aprendizado dos principais conceitos de Programação Orientada a Objetos e da linguagem Java.

Os códigos estão organizados de acordo com os conteúdos e exercícios desenvolvidos durante as aulas.

🎯 Objetivos
Praticar a linguagem Java;
Desenvolver a lógica de programação;
Compreender os fundamentos da Programação Orientada a Objetos;
Aplicar conceitos de classes e objetos;
Desenvolver métodos e construtores;
Trabalhar com encapsulamento;
Compreender herança e polimorfismo;
Praticar a organização e estruturação de projetos Java.
